# WorkMeOut

A simple workout app. Build a workout, press start, follow the timer.

**Try it:** [work-me-out.jjdance-dev.workers.dev](https://work-me-out.jjdance-dev.workers.dev/)

> This is a personal project, built mainly to learn how Progressive Web Apps (PWAs) work. It isn't a product and has no roadmap, so expect things to change or occasionally break.

## What it does

- **Browse ~800 exercises** with pictures, instructions and the muscles they work. Search and filter by muscle, equipment, level and more.
- **Add your own exercises** if the one you want isn't there.
- **Build workouts** from exercises and rests, with sets, reps or timed sets, and rest between sets. Filter by body area, muscles and the equipment you have.
- **Run a session** with a guided timer that beeps when time's up, keeps the screen awake, and lets you look up an exercise mid-workout.
- **Works offline** once installed to your home screen, which is useful in gyms with no signal.

## PWA features

| Feature | How it works |
| --- | --- |
| Installable | A web app manifest (name, icons, colours, `standalone` display) generated by [`vite-plugin-pwa`](https://vite-pwa-org.netlify.app/) |
| Offline | A Workbox service worker precaches the app shell and the full exercise list on install |
| Offline images | Exercise images are cached on first view (cache-first), and saving a workout pre-fetches the images it uses |
| Screen stays on | The [Screen Wake Lock API](https://developer.mozilla.org/docs/Web/API/Screen_Wake_Lock_API) while a session is running |
| Timer beeps | The Web Audio API, unlocked by the first tap |
| Offline badge | `navigator.onLine` plus online/offline events |
| No backend | Workouts and custom exercises are stored in `localStorage` on your device only |

## Built with

- [React 19](https://react.dev/) + TypeScript
- [Vite](https://vite.dev/) + [`vite-plugin-pwa`](https://vite-pwa-org.netlify.app/) (Workbox under the hood)

## Running it locally

You'll need Node and [pnpm](https://pnpm.io/).

```bash
pnpm install
```

```bash
pnpm dev
```

The service worker also runs in dev, so you can test offline behaviour without building. To test a production build:

```bash
pnpm build && pnpm preview
```

To test on your phone, run the dev server with `--host` and open your machine's LAN address. Some PWA features (service workers, wake lock) only work over HTTPS or `localhost`, so they won't all work over plain LAN `http://`.

### Deploying

The build output in `dist/` is served as static assets by Cloudflare Workers (see `wrangler.jsonc`):

```bash
pnpm build && pnpm dlx wrangler deploy
```

    ExerciseProvider   fetches and shares the exercise list
